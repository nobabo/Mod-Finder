# 전시회 코드 리뷰 반영 — 0.2.3

검색·저장·추천·화면 상태와 웹/Windows/Android의 동작 차이를 수정했습니다.

| 보고서 항목 | 반영 내용 |
| --- | --- |
| Android 관련도 | 한국어 이름·요약과 검색어 변형을 대조하고 출처 순위의 RRF 점수와 제목 완전 일치 점수를 반영합니다. |
| Steam 추가 페이지 | 커서에 누적 위치를 넣어 1·21·41 순위를 유지합니다. 이전 커서도 읽을 수 있습니다. |
| 전체 게임 카테고리 | 실행 단계의 중복 제거는 유지하고, 계획 생성 전에 잘못된 카테고리 범위를 거절합니다. |
| 추천 후보 | 기본 목록에 관심 검색어·주제의 추가 검색 결과를 합칩니다. 추가 키워드는 최대 3개이며 동시 요청은 4개입니다. |
| 관심 신호 | 모드 제목·요약·태그에서 주제만 추출합니다. 링크 열기와 즐겨찾기 추가를 반영하고, 기록 삭제 시 신호도 지웁니다. 제공자 응답을 관심 신호에 저장하지 않습니다. |
| 추천 목록 구조 | 실제 목록 자식 요소에 폭과 테두리 스타일을 적용하며 불필요한 순위 번호는 추가하지 않습니다. |
| Thunderstore 복원 | 커뮤니티·네임스페이스·패키지 이름을 확인하는 상세 API로 참조를 복원합니다. 상세 데이터 저장은 기존 opt-in 정책을 따릅니다. |
| 초기 저장 데이터 | 로컬 상태를 즉시 표시한 뒤 외부 참조를 갱신합니다. 갱신 중 삭제·추가·폴더 변경을 덮어쓰지 않습니다. |
| Android 기능 | 맞춤 추천·관심 신호·폴더 홈 바로가기, 병합 결과의 저장 판별, 언어 변경 시 요약 로딩, 원문 제목과 Steam 통계 이름을 반영했습니다. |
| Android 대체 검색 계획 | 한국어 띄어쓰기·커뮤니티 이름·부분 일치·검수된 단복수 사전을 동봉합니다. 계획 API 실패 시 로컬 계획으로 대체합니다. |
| 유리 효과 | 자식 렌즈가 없는 필터 메뉴의 추가·제거도 패널 목록을 갱신합니다. |
| 상세 화면·히스토리 | 히스토리에는 출처별 참조만 남기고 메모리가 없는 경우 API에서 다시 조회합니다. 복원할 수 없는 참조는 제거합니다. 홈 목록의 대체 출처와 저장 상태도 유지합니다. |
| 겹친 창 | 공통 스크롤 잠금·최상위 포커스 처리를 적용해 창이 열린 순서와 다르게 닫혀도 잠금을 복원합니다. |
| 언어·번역 로딩 | 언어 변경 시 검색 상태를 갱신하고, 카드마다 실행하던 요약 로딩을 목록 단위로 모았습니다. |
| 요청 제한 | 대기 초와 초기화 시각을 구분합니다. Worker 인스턴스에서는 호스트별 쿨다운 숫자만 공유하며 요청·응답·인증 정보·Promise는 공유하지 않습니다. 인스턴스 간 공용 쿨다운은 아닙니다. |
| API 일관성 | 경로를 한 번 디코딩하며 지역·우선순위가 있는 언어 헤더를 처리합니다. 로컬 서버도 405와 설치파일 스트리밍을 지원합니다. |
| 버전·생성물 | 앱 버전은 `package.json`, Android 업데이트 코드는 `tooling/config/android.json`에서 읽습니다. 이전 Tauri Android 스캐폴딩은 추적 대상에서 제거했습니다. |

회귀 검사는 `npm test`와 Android release 단위 테스트에 포함합니다. 실제 브라우저 검사는 `tooling/scripts/verify-review-browser.js`를 Playwright CLI의 `run-code --filename`으로 실행합니다. 이 스크립트는 별도의 테스트 브라우저에서 로컬 저장 데이터와 API 응답을 고정하며, 캡처는 `output/playwright/`에 저장합니다.

Android 실제 기기의 화면·성능·업데이트 설치는 연결된 기기가 있을 때 별도 확인해야 합니다. 빌드·서명 검사만으로 실기기 실행을 검증했다고 간주하지 않습니다.
