# 배경과 카드 UI

14개 게임마다 실제 스크린샷 6장과 로고를 로컬 에셋으로 제공합니다. `src/shared/data/backgrounds.json`과 `src/shared/data/logos.json`에 원본 URL과 출처를 기록했습니다. Steam 공식 상점 이미지와 Minecraft 공식 웹사이트 이미지를 사용하며 게임 이미지와 로고의 권리는 각 권리자에게 있습니다.

`src/web/Atmosphere.tsx`는 선택한 게임 범위의 이미지만 순차적으로 불러옵니다. 배경은 20초마다 2.4초 동안 전환합니다. 게임명, 이미지 수, 재생 버튼은 표시하지 않습니다.

`src/web/lib/glass-renderer.ts`는 사진에 약한 블러를 한 번 적용한 뒤, 느리게 움직이는 오로라와 굴절·색 분산·반사광을 WebGL로 렌더링합니다. 렌더링은 최대 30fps, 220만 픽셀로 제한하며 숨겨진 창에서는 중지합니다. WebGL 사용 불가 또는 컨텍스트 손실 시 CSS 배경으로 전환하고 컨텍스트 복구 시 다시 렌더링합니다. 시스템의 동작 줄이기 설정에서는 배경 전환과 지속 애니메이션을 중지합니다.

게임·장르·버전 검색 입력창도 같은 유리 표면을 사용합니다. 입력창 배경은 투명하게 두며, 테마 색 테두리는 유지합니다. 웹 설정에 있는 웹 / 앱 다운로드 카드는 웹 주소·Windows 설치파일·Android APK를 연결하며 네이티브 앱에서는 표시하지 않습니다.

`src/web/lib/themes.ts`에서 14개 테마의 색을 관리합니다. 배경 오로라, 검색창과 카드 외곽선, 아이콘에 같은 팔레트를 적용하고 선택을 기기에 저장합니다.

게임 선택은 가운데 제목과 검색창, 한 줄의 로고 카드로 구성합니다. 전체 게임으로 돌아가는 선택지는 카드에 포함합니다. 화면 양 끝 각각 34% 영역에서 마우스 위치에 따라 천천히 가속하고, 중앙으로 돌아오면 감속합니다. 마우스·터치 드래그와 가로 스크롤, 방향 버튼도 지원합니다. 6px 이상 드래그한 동작은 카드 선택으로 처리하지 않습니다.

설정 메뉴는 모드 둘러보기·즐겨찾기·최근 기록·테마·언어 카드 한 줄입니다. 테마와 언어 카드는 별도의 선택 화면을 열며, 뒤로 버튼이나 Escape로 카드 메뉴에 돌아옵니다. 한국어·영어·일본어·중국어 간체·스페인어·독일어·프랑스어를 언어별 JSON으로 관리합니다. 카드 줄은 마우스와 터치로 넘길 수 있습니다. 열고 닫을 때 검색창의 값·플레이스홀더·게임 아이콘을 유지합니다. 불필요한 배경 보조 UI를 추가하지 않는 원칙은 `AGENTS.md`에 명시했습니다.

게임 또는 장르를 바꾸면 새 범위의 첫 이미지를 디코딩한 즉시 교체합니다. 같은 범위의 사진은 2.4초 동안 부드럽게 전환하며, 숨겨진 탭에서 지난 시간을 전환 시간에 더하지 않습니다. 다음 사진은 미리 로드하고, 전환 중 도착한 사진은 대기시켜 중간 장면을 덮어쓰지 않습니다. CSS 대체 배경도 두 레이어로 전환합니다.

자동 카드 넘김은 0에서 시작해 2.4초 동안 smoothstep 곡선으로 가속 목표를 올립니다. 오로라는 두 테마 색을 화면의 넓은 영역에 분포시키고 시간에 따라 섞는 비율을 변화시킵니다.

검색창 안내는 “검색할 모드를 입력하세요.”입니다. 검색 결과의 제목·출처 탭·상태 라벨과 카드 하단 버튼·게임 이름 라벨을 제거했습니다. 필터 버튼은 검색 버튼 옆에 있고, 모드 로고는 원본 사이트를 열며 제목은 상세 화면을 엽니다. `tooling/scripts/verify-ui.js`는 이 동작과 페이지를 추가로 불러온 뒤의 검색 우선순위를 확인하는 결정적 테스트입니다.

현재 화면 검증 절차는 [검증 방법](VERIFICATION.md)을 참고하세요. 캡처는 `output/playwright/`에 저장하며 Git에 포함하지 않습니다.
