# 순위표 한글 이름

- 한국어 화면의 다운로드·구독 순위는 `src/shared/locales/mods.ko.json`의 `출처:scope:모드ID` 키로 이름을 표시합니다. 마인크래프트 외 13개 게임의 상위 30개 항목을 2026-09-30 운영 API 응답과 대조해 등록했습니다.
- 모드의 원래 제목·URL·ID·순위·지표는 보존합니다. 한국어 이름으로 검색하면 해당 출처의 원래 제목으로 요청하고, 다른 언어에서는 원래 제목을 표시합니다. 새로 순위에 진입한 미등록 모드는 원래 제목을 표시합니다.
- SKSE, CBBE, R2API 등 식별에 유용한 약어와 발음이 불분명한 제작자·라이브러리 이름은 유지합니다. 일반 단어와 설명은 한글로 표시합니다.
- 검색 순위 이름은 `src/shared/data/community-mods.json`의 게임별 ID에 등록하고 기존 `community-rankings.json`에도 반영합니다. 집계 원문·횟수·순서·수집 시각은 변경하지 않았습니다. 이후 집계에서도 같은 이름을 사용합니다.
- `BepInEx` 태그는 공통 태그 사전에서 `베핀엑스`로 표시합니다.
