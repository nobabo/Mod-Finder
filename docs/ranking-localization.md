# 순위표 한글 이름

- 한국어 화면의 다운로드·구독 순위는 `src/shared/locales/mods.ko.json`의 `출처:scope:모드ID` 키로 이름을 표시합니다. 마인크래프트 외 13개 게임의 상위 30개 항목을 2026-09-30 운영 API 응답과 대조해 등록했습니다.
- 모드의 원래 제목·URL·ID·순위·지표는 보존합니다. 한국어 이름으로 검색하면 해당 출처의 원래 제목으로 요청하고, 다른 언어에서는 원래 제목을 표시합니다. 새로 순위에 진입한 미등록 모드는 원래 제목을 표시합니다.
- SKSE, CBBE, R2API 등 식별에 유용한 약어와 발음이 불분명한 제작자·라이브러리 이름은 유지합니다. 일반 단어와 설명은 한글로 표시합니다.
- 검색 순위 이름은 `src/shared/data/community-mods.json`의 게임별 ID에 등록하고 기존 `community-rankings.json`에도 반영합니다. 집계 원문·횟수·순서·수집 시각은 변경하지 않았습니다. 이후 집계에서도 같은 이름을 사용합니다.
- `BepInEx` 태그는 공통 태그 사전에서 `베핀엑스`로 표시합니다.

## 한글 이름·부분 이름 검색

- 다운로드 순위의 출처별 번역 이름과 검색 순위의 게임별 한글 이름을 함께 검색 힌트로 사용합니다. 두 글자 이상의 한글 부분 이름과 띄어쓰기 차이를 지원합니다. 영문 검색어는 그대로 유지합니다.
- 정확한 이름은 해당 원문 제목들로, 부분 이름은 일치하는 제목들과 기존 키워드로 검색합니다. 출처별로 검토된 한글 설명도 검색 힌트에 포함합니다. 여러 항목이 일치하면 하나로 합치지 않고 각각 검색하며, 결과 중복은 기존 출처·scope·ID 및 검증된 교차 출처 연결로만 제거합니다.
- 검색 요청은 게임·출처·필터·정렬을 유지하고 검색어별로 페이지 커서를 관리합니다. 보완 검색은 기존 검색에 결과가 있어도 실행합니다. 한 출처당 최대 8개 검색어, 동시 요청 4개로 제한합니다. 광범위한 부분 검색에서는 제목 힌트가 제한될 수 있지만 일반 키워드 검색은 유지합니다.
- 2026-10-04 운영 API에서 `디시즈`와 `검시관`의 검색 누락, `칼라미`의 본체 누락을 확인했습니다. 디시즈드크래프트는 CurseForge `432:490660`의 실제 제목·설명으로 좀비 아포칼립스임을 확인해 한글 이름과 설명을 등록했습니다. `좀비`는 `zombies` 대신 제목·설명에 사용된 `zombie`로 전달하며, `DeceasedCraft` 제목 검색도 함께 수행합니다.
- 검색 힌트 자체를 결과 카드로 만들지 않습니다. 외부 출처가 실제 반환한 항목만 표시하므로 서비스 장애·원본 삭제·호환성 필터에 따른 제외는 그대로 반영됩니다.
