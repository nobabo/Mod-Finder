# 즐겨찾기·태그·순위

## 즐겨찾기

카드와 상세 화면의 북마크 버튼으로 저장·해제합니다. 설정 메뉴 또는 모바일 하단 메뉴에서 즐겨찾기를 열면 폴더 생성, 이름 변경, 모드 이동, 폴더 삭제를 할 수 있습니다. 폴더를 삭제하면 포함된 모드는 미분류에 남습니다. 저장 데이터는 브라우저의 기존 로컬 저장소 또는 네이티브 앱의 SQLite에 보관됩니다. 폴더 필드가 없는 이전 데이터도 그대로 읽습니다.

CurseForge API 데이터에 대한 기존 저장 제한을 유지합니다. 모든 출처에 즐겨찾기 버튼을 표시합니다. CurseForge는 사용자 즐겨찾기의 출처·게임·프로젝트 식별자만 저장하고, 다시 열 때 상세 API에서 내용을 조회합니다. 조회 실패 시에도 식별자와 폴더 배치를 보존하여 저장 해제·이동이 가능합니다. 확인된 동일 프로젝트에서 이미 저장한 다른 출처가 있으면 그 저장 상태를 사용합니다. Thunderstore는 사용자가 직접 저장한 즐겨찾기만 보관하며 자동 수집·공유 캐시는 추가하지 않습니다.

## 태그

게임별 장르 카드는 여러 장을 선택할 수 있습니다. 다시 누르면 해제하고 전체 장르를 누르면 선택을 비웁니다. 각 태그의 기존 API 검색을 독립적으로 조회·페이지 처리합니다. 동일한 출처 ID의 결과는 한 번만 표시하면서 일치한 태그 근거를 합칩니다.

선택한 태그가 많이 일치하는 결과부터 표시합니다. 모두 일치하는 결과가 먼저, 일부만 일치하는 결과가 다음이며 같은 일치 개수 안에서는 사용자가 선택한 정렬을 유지합니다. 최근 검색에서도 선택한 태그를 복원합니다. 아직 가져오지 않은 페이지의 모드는 추가 조회 시 순위에 반영됩니다.

## 검색·다운로드 순위

메인 화면 검색창 바로 아래의 리퀴드 글래스 패널에서 확인합니다.

- 마인크래프트 검색 순위: 검색 횟수 API 대신 사용자가 지정한 [스티브 갤러리 모드 게시판](https://gall.dcinside.com/mgallery/board/lists/?id=steve&sort_type=N&search_head=70&page=1)의 1–15페이지 글 제목을 집계합니다. 2026-09-29 수집본은 중복을 제거한 750개 글입니다. 같은 글에서 동일 모드팩이 여러 번 등장해도 1회이며, 서로 다른 모드팩을 함께 언급하면 각각 1회입니다. 확인한 모드팩 이름과 별칭만 집계하고 개별 모드·버전이 불분명한 이름은 모드팩으로 추정하지 않습니다. 화면에는 지정된 한글 이름과 순위만 표시하며 집계 근거와 수집 날짜는 데이터 파일에 보존합니다. 주기적 자동 갱신은 없습니다.
- 다운로드 순위: 선택한 게임의 모든 출처를 다운로드순으로 최대 3페이지씩 조회하여 하나의 상위 30개 목록으로 정렬합니다. 페이지당 10개씩 이전·다음 버튼으로 이동합니다. 확인된 동일 프로젝트는 한 번만 표시하고 다운로드 수가 큰 출처를 대표로 사용합니다. 마인크래프트는 모드팩을 조회합니다. 다른 게임은 해당 출처의 모드 목록을 사용하며 Steam은 누적 구독 순위로 표시합니다. 출처별 통계를 합산하지 않습니다. API 인덱스 갱신 시점에 따라 사이트의 현재 순위와 차이가 날 수 있습니다.
- 게시판 항목을 누르면 실제 모드팩 검색을 시작합니다. 게시판 이름이나 외부 링크를 API 검색 결과로 꾸미지 않습니다. API 조회 실패 시 이전 순위를 지우고 재시도를 제공합니다.

공식 정렬 문서: [Modrinth 검색](https://docs.modrinth.com/api/operations/searchprojects/), [CurseForge REST](https://docs.curseforge.com/rest-api/).

### 게시판 집계 갱신

저장소 루트에서 순서대로 실행합니다.

```powershell
node tooling/scripts/collect-community-titles.mjs
npx tsx tooling/scripts/build-community-ranking.ts
```

수집 원문은 `output/research/`에만 저장됩니다. 15페이지가 모두 수집된 경우에만 `src/shared/data/community-ranking.json`을 원자적으로 교체합니다. 집계 파일에는 글 ID와 횟수를 남겨 검증할 수 있습니다. 별칭은 `src/shared/community-ranking.ts`에서 관리합니다.

## 검증

`tooling/tests/collections.test.ts`는 이전 저장 데이터 읽기, 폴더 이동·저장 해제, 태그별 페이지 구분·우선순위, 제목 중복 집계와 스냅샷 완전성을 검사합니다. `tooling/scripts/verify-collections.js`는 Playwright CLI에서 데스크톱·모바일의 저장·폴더·태그·TOP 30 페이지 이동·조회 실패·재시도를 검증합니다. 캡처는 `output/playwright/`에 저장됩니다.
