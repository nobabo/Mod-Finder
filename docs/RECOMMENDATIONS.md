# 기기 내 맞춤 추천

홈의 맞춤 추천 탭은 실제 API 검색 결과를 기기에서 정렬한다. 선택한 게임을 우선하며 전체 게임에서는 최근 관심도가 가장 높은 게임을 사용한다. 기존 검색 정렬과 필터에는 개입하지 않는다. 추천 후보는 해당 게임의 검색 API가 반환하는 범위에 한정된다.

검색 제출은 2점, 게임 선택은 1점, 원본 모드 페이지 열기 시도는 4점이다. 실제 게임 실행·플레이 시간이나 원본 사이트 안에서의 행동은 측정하지 않는다. 팝업 차단 여부는 브라우저에서 확정할 수 없다. 복구용 외부 검색 링크는 모드 관심 기록으로 사용하지 않는다.

검색어와 클릭한 모드 태그를 고정된 관심 분류에 대응한다. 공급자의 원본 태그·설명·모드 데이터는 분석 기록에 저장하지 않는다. 검색어의 텍스트 일치도도 후보 점수에 반영한다. 게임이 다른 기록은 해당 모드 점수에 영향을 주지 않는다. 14일마다 영향력이 절반으로 줄며 90일 이전 기록은 무시한다. 최대 200개를 보관하고 30초 내 같은 신호는 중복 반영하지 않는다. 분류 사전 밖의 태그는 게임 관심 신호만 제공한다.

관심 기록은 기존 로컬 저장소(웹 localStorage, 네이티브 SQLite)에만 보관한다. 서버나 외부 분석 서비스에 전송하지 않는다. 검색 기록 지우기는 검색 기록과 관심 기록을 함께 초기화한다. 즐겨찾기는 유지하지만 이를 이용해 지운 관심 기록을 재구성하지 않는다. 검색 기록 없이 클릭 기록만 있어도 삭제 버튼이 표시된다.

신규 사용자는 기본 검색 순서를 사용한다. 추천은 모드 간 호환성을 보증하지 않는다. 호환 정보가 없는 항목은 기존 null 값을 유지한다.
