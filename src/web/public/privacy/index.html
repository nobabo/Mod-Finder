Mod Finder

개인정보처리방침

Android 앱 0.2.0 · 시행일 2026년 9월 30일

English

이 방침은 Mod Finder Android 앱에서 어떤 정보가 기기에 남고, 검색과 이미지 표시를 위해 어떤 정보가 네트워크로 전송되는지 설명합니다.

1. 기기에 저장하는 정보

즐겨찾기와 폴더, 최근 검색어, 비교 목록, 테마와 언어 설정은 앱의 전용 저장 공간에 저장합니다. 최근 검색은 최대 20개를 유지합니다. 이 정보는 계정에 업로드하거나 다른 사용자와 공유하지 않습니다. Android 클라우드 백업과 기기 간 자동 전송도 사용하지 않습니다.

검색 기록은 앱의 최근 검색 화면에서 지울 수 있습니다. 즐겨찾기는 각 항목의 저장을 해제하면 삭제됩니다. Android 설정에서 앱 데이터를 지우거나 앱을 제거하면 앱의 로컬 데이터가 삭제됩니다. 이전 Mod Finder 앱의 로컬 데이터가 있으면 업데이트 후 이어서 읽습니다.

2. 검색할 때 전송하는 정보

검색어, 선택한 게임과 출처, 버전·로더·카테고리 같은 검색 조건, 페이지 커서, 표시 언어를 HTTPS로 Mod Finder API에 전송합니다. 즐겨찾기 정보를 새로 읽을 때는 해당 모드의 출처와 식별자를 전송합니다.

API는 요청을 처리하기 위해 Modrinth, CurseForge, Thunderstore, Nexus Mods 또는 Steam 등 선택한 출처에 필요한 검색 조건과 식별자를 전달합니다. Mod Finder는 서버 데이터베이스에 개인별 검색 기록을 보관하지 않으며, 앱의 오류 로그에 검색어·전체 요청 주소·IP 주소를 기록하지 않습니다.

3. 네트워크와 외부 사이트

API와 웹 페이지는 Cloudflare를 통해 제공됩니다. Cloudflare는 통신·보안·요청 제한을 위해 IP 주소 등 네트워크 정보를 처리할 수 있습니다. 모드 아이콘은 해당 이미지 제공 서버에서 직접 불러오므로 그 서버에도 IP 주소와 이미지 요청이 전달됩니다. 이러한 제공자의 보안·운영 데이터 처리는 각 제공자의 방침을 따릅니다.

원본 사이트 링크를 누르면 외부 브라우저가 열립니다. 외부 사이트에서 이루어지는 로그인·쿠키·다운로드는 해당 사이트의 방침을 따릅니다.

4. 권한과 분석 도구

앱은 인터넷 연결 권한을 사용합니다. 위치, 연락처, 카메라, 마이크, 사진 접근을 요구하지 않습니다. 앱 내 회원가입, 광고, 인앱 결제, 광고 식별자 수집, 별도의 이용 분석·추적 SDK는 사용하지 않습니다.

5. 문의와 변경

데이터 처리에 관한 문의는 Mod Finder 개발자 문의로 접수할 수 있습니다. 공개 게시판이므로 민감한 개인정보는 기재하지 마세요. 앱의 처리 방식이 바뀌면 이 페이지와 시행일을 갱신합니다.

Privacy policy

Android app 0.2.0 · Effective September 30, 2026

Data on your device

Mod Finder stores bookmarks, folders, up to 20 recent searches, comparison selections, theme and language settings in private app storage. It does not upload these lists to an account or share them with other users. Android cloud backup and automatic device transfer are disabled. You can remove bookmarks and search history in the app. Clearing app data or uninstalling removes local app data. An update can read local data from a previous Mod Finder installation.

Search requests

The app sends your query, game, source, filters, pagination cursor and display language to the Mod Finder API over HTTPS. Refreshing a bookmark sends its source and identifier. The API passes the necessary search parameters to the relevant provider: Modrinth, CurseForge, Thunderstore, Nexus Mods or Steam. Mod Finder does not store per-user search history in a server database or write queries, full request URLs or IP addresses to its application error logs.

Network providers and external links

Cloudflare hosts the API and website and may process IP addresses and other network information for delivery, security and rate limiting. Mod icons load directly from their image providers, which receive your IP address and image request. These providers handle their operational data under their own policies. Opening a source link launches your external browser; the source website's policy applies to its login, cookies and downloads.

Permissions

The app uses internet access. It does not request location, contacts, camera, microphone or photo access. There are no app accounts, ads, in-app purchases, advertising ID collection, or separate analytics or tracking SDKs.

Contact and updates

Contact the developer through Mod Finder support. This is a public issue tracker; do not post sensitive personal information. We update this page and its effective date when the app's data practices change.

See Cloudflare's privacy policy.
